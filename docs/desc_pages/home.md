# Главная / матчи

**URL:** `/`  
**Статус:** MVP  
**Inertia:** `Matches/Index`

## Зачем страница пользователю

Точка входа: выбрать турнир или режим **«Все»** (все активные лиги), за секунды увидеть матчи и перейти к вероятностям. Справа — контекст лиги (таблица, бомбардиры) и лёгкий промо-контент. Страница не «лендинг с маркетингом», а рабочий каталог матчей с обогащением.

## Что на экране

### Иерархия (сверху вниз / desktop)

1. **Шапка:** бренд MatchIQ; ссылки «Рейтинг», «Войти» / «Регистрация» (гость) или «Мои выборы» + выход (авторизованный). Без subtitle / breadcrumb под логотипом.
2. **Меню турниров / лиг (выше матчей, обязательный блок):**
   - компактная панель-пикер (не аккордеоны и не крупные карточки лиг);
   - **над заголовком «Турниры»** — чипы **текущего выбора** (режим «Все» или выбранные лиги); у каждой лиги в чипе — **×** (снять с выбора); снятие последней лиги → откат к «Все»; у чипа «Все» крестика нет;
   - **мультивыбор live-лиг** (например РПЛ + ФНЛ или РПЛ + UCL) — в списке матчи из всех выбранных; «скоро» по-прежнему нельзя выбрать;
   - пункт **«Все»** — компактный чип слева в навигации; эксклюзивный режим: нельзя сочетать с конкретной лигой; выбор лиги при «Все» снимает «Все» и оставляет эту лигу; выбор «Все» очищает индивидуальные;
   - **горизонтальные табы стран** (Россия, Англия, Испания…; UCL — «Европа») + **компактные чипы лиг** только для активной страны; у таба — точка live или счётчик выбранных;
   - в чипе лиги: short-код (полное имя в `title`);
   - **активные (live)** — кликабельны, добавляют/снимают лигу в мультивыборе; виджеты таблицы/бомбардиров — по первой выбранной лиге (для «Все» — первая live);
   - **неактивные («скоро»)** — видны в чипах страны, disabled + метка «скоро»; toast «Лига в разработке»;
   - без helper-текста «Мультивыбор · …» в шапке панели;
   - по умолчанию — **«Все»** (`?league=all`); query `league` + день (`period` или `date`);
   - URL мультивыбора: `?league=rpl,ucl` или повторные/`league[]` параметры; `league=all` — все live;
   - отдельный URL `/leagues` не нужен.
3. **Двухколоночный рабочий блок (desktop ~60–65% / ~35–40%):**
   - **Слева — матчи:**
     - фильтр дня: **Вчера | Сегодня | Завтра | календарь** (для текущего фильтра лиг); по умолчанию — сегодня;
     - URL дня: `?period=yesterday|today|tomorrow` или `?date=YYYY-MM-DD` (календарь; если день = вчера/сегодня/завтра — нормализуется в `period`);
     - в шапке панели матчей — компактный контекст фильтра (например «Все · Россия · РПЛ» или «РПЛ · ФНЛ»);
     - группировка по дате (Сегодня / Завтра / …);
     - строка: время/Live · хозяева — гости · счёт (если есть); в режиме «Все» или при нескольких лигах — короткий код лиги над названием матча;
     - опциональный тизер продукта: топ-исход с вероятностью `%` («открыть события») — без превращения списка в таблицу коэффициентов Forebet.
   - **Справа — виджеты (demo OK):**
     - турнирная таблица выбранной (или top live при «Все») лиги;
     - лучшие бомбардиры лиги;
     - «скорострелы» / топ голов за год (компактный блок, кросс-лига);
     - новости (3–5 карточек) — слот под будущий промо.
4. **Футер лёгкий:** фраза-правило рейтинга («Откройте матч → …») / «Как это работает».

### Mobile

Стек: шапка → пикер лиг (горизонтальные табы стран + чипы) → день (Вчера/Сегодня/Завтра/календарь) + матчи → виджеты **табами** (Таблица / Бомбардиры / Скорострелы / Новости) ниже списка.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading | Скелетон меню лиг + списка матчей + правых панелей |
| Empty (нет матчей на дату) | «На эту дату матчей нет» + другой день |
| Тап по «скоро» | Матчи не меняются; toast «Скоро» |
| Нет ни одной активной лиги | «Матчи скоро появятся» — без фейковых матчей |
| Error | «Не удалось загрузить матчи» + «Повторить» |

## Что можно сделать

- Выбрать «Все» или одну/несколько активных лиг в меню турниров (по странам); снять лигу крестиком на чипе.
- Переключить день (вчера / сегодня / завтра) или выбрать дату в календаре месяца.
- Открыть матч → `/matches/{id}`.
- Просмотреть таблицу / бомбардиров / скорострелов / новости (пока demo).
- Перейти в рейтинг, вход, регистрацию, профиль; выйти.

## UX-заметки

- **Общие паттерны референсов (не клонить один сайт):** multi-column IA; навигация по лигам/странам; match-centric колонка; right-rail enrichment; явные active states.
- **Уникальность MatchIQ:** brand-first; вероятности 0–100 как продукт (тизер в строке матча); светлый pitch daylight (не тёмный клон FotMob/GolStat); неактивные лиги «скоро»; CTA рейтинга сдержанный.
- Данные лиг (`id`, страна, название, short, `status: live | soon`) с бэка — фронт не хардкодит «только РПЛ». Фильтр `all` режется до live-лиг на клиенте/бэке; мультивыбор — только live.
- Чипы выбора — индикатор текущего фильтра над «Турниры», не замена пикера.
- IA: табы стран + компактные чипы лиг (без аккордеонов и крупных карточек); меньше вертикального объёма.
- Панели виджетов — контейнеры данных/сканирования; не карточный коллаж в hero.
- Бренд заметен в шапке; без instructional hero / value-блока над турнирами.

## Связи с другими страницами

- → `/leaderboard`, `/login`, `/register`, `/me`.
