# Главная / матчи

**URL:** `/`  
**Статус:** MVP  
**Inertia:** `Matches/Index`

## Зачем страница пользователю

Точка входа: выбрать турнир или режим **«Все»** (все активные лиги), за секунды увидеть матчи и перейти к вероятностям. Сверху — «Матч дня» с вероятностями; справа — контекст лиги (таблица, бомбардиры) и AI-превью матчей. Страница не «лендинг с маркетингом», а рабочий каталог матчей с обогащением.

## Что на экране

### Иерархия (сверху вниз / desktop)

1. **Шапка (одна компактная строка, ~56px):** слева бренд MatchIQ, рядом верхнее меню **Матчи · Турниры · Клубы · Рейтинг** (активный пункт — зелёный с подчёркиванием); справа «Войти» / «Регистрация» (гость) или имя профиля + «Выйти» (авторизованный). «Матчи» → `/`; «Турниры» → `/#tournaments` (якорь на пикер лиг; страницы-списка турниров нет); «Клубы» — пока без страницы-списка: неактивный пункт с меткой «скоро» (не ссылка, без 404); «Рейтинг» → `/leaderboard`. На mobile (<md) — бургер справа, меню раскрывается панелью под шапкой (пункты + вход/профиль), закрывается при переходе. Без subtitle / breadcrumb под логотипом.
2. **Фильтр лиг — одна sticky-строка** (прилипает к верху при прокрутке, матчи начинаются выше сгиба):
   - слева чип **«Все»**, затем **топ-лиги чипами** с флагом страны и short-кодом (live-лиги по `sort_order`, затем «скоро»; максимум 7 — `TOP_LEAGUE_CHIPS` в `Index.vue`), справа кнопка-поповер **«Все лиги +N»**;
   - поповер: табы стран (Россия, Англия… UCL — «Европа») + чипы лиг активной страны; закрывается по клику вне, Esc и выбору «Все»; «скоро» видны там и в топ-чипах, disabled + метка «скоро», подсказка «Лига в разработке — скоро»;
   - **мультивыбор live-лиг** (РПЛ + ФНЛ…): клик по чипу добавляет/снимает лигу; выбранная лига вне топ-чипов показывается дополнительным чипом с **×**; снятие последней → «Все»;
   - **«Все»** эксклюзивен: выбор лиги при «Все» снимает «Все», «Все» очищает индивидуальные;
   - по умолчанию `?league=all`; query `league` + день (`period` или `date`); `?league=rpl,ucl` или повторные/`league[]`; виджеты рейла — по первой выбранной лиге (для «Все» — первая live);
   - отдельного блока «Турниры» над списком и отдельных чипов выбора нет; якорь `/#tournaments` ведёт на эту строку.
3. **Двухколоночный рабочий блок (desktop ~60–65% / ~35–40%):**
   - **Слева:**
     - фильтр дня: **Вчера | Сегодня | Завтра | календарь**; по умолчанию — сегодня; `?period=yesterday|today|tomorrow` или `?date=YYYY-MM-DD` (день = вчера/сегодня/завтра нормализуется в `period`);
     - **«Матч дня»** над списком (если есть несыгранные матчи в текущем фильтре): пара с логотипами, время и лига, три вероятности **П1 / Х / П2** крупно (максимум залит брендовым зелёным), до 3 **лучших событий** чипами, ~2 строки **AI-превью** (`match_previews.preview_text`, line-clamp 2) и кнопка «События» → `/matches/{id}`. Выбор: максимум из max(П1, Х, П2) среди несыгранных матчей; если прогнозов ещё нет — ближайший по времени. Без прогноза плитки показывают «—», без превью — заглушка «AI-превью появится вместе с прогнозом модели.»;
     - в шапке панели матчей — контекст фильтра («Все · Россия · РПЛ»);
     - **группировка по турниру/лиге** (если у турнира есть страница [tournament.md](tournament.md) — заголовок ссылка на `/tournaments/{id}`, иначе текст; поле `tournament_id`); порядок групп: `sort_order`, при равенстве — алфавит;
     - внутри лиги: **не начались → идут → завершены**, внутри статуса — по времени;
     - **строка матча** (две строки команд): время/Live/статус · на каждой строке логотип команды (или инициалы, если `logo_url` нет), название, форма палочками (зелёный В, жёлтый Н, красный П), голы; справа **П1 / Х / П2 крупными плитками** с `%` (максимум — зелёная плитка) и под ними чип **лучшего события** («ТБ 2.5 · 67%»). У завершённых вероятности скрыты, остаются голы. Без прогноза — приглушённые плитки «—». Текста «открыть события» нет — вся строка ссылка на матч. На узкой ширине (<34rem контейнера) плитки уходят на вторую строку;
     - **лучшие события:** до 3 исходов из текущего прогноза (`prediction_outcomes`) по популярным рынкам (`market_types.is_popular`), кроме 1X2, по убыванию вероятности; подпись — исход + линия («ТБ 2.5»), название рынка в `title`. Пока модель не пишет рынки — пусто, чип не рисуется.
   - **Справа — правый рейл:**
     - **один блок с вкладками «Таблица / Бомбардиры»** для выбранной (или первой live) лиги; справа в шапке — ссылка на страницу турнира (`widgets.league.tournament_id`);
     - **«Превью матчей»** (вместо новостей): до 5 несыгранных матчей текущего фильтра; заголовок — первое предложение AI-превью (матчи с превью выше), иначе вопрос-заглушка «Команда А — Команда Б: кто возьмёт верх?» с меткой «скоро»; клик → матч;
     - **«Скорострелы · топ мира»** — свёрнутый `<details>` под ними (топ-5 Гол/90 за 12 месяцев, кросс-лига, порог **300 минут**, `match_player_stats`; не зависит от фильтра; блок скрыт, пока данных нет).
4. **Полоса доверия (под основным блоком, тонкая):** «**99%** точность модели» · «Как мы считаем» (раскрывает 2 строки про шкалу 0–100 и очки) · CTA «Выбери событие — попади в рейтинг →» → `/leaderboard`. **Цифра 99% — заглушка:** приходит с бэка как `modelStats = { hit_rate, is_placeholder: true }`, значение из `config('matchiq.model_hit_rate_placeholder')`; позже заменить реальным hit-rate по разрешённым `prediction_outcomes.is_hit` (и убрать `is_placeholder`). В `title` плашки — пометка о временном значении.
5. **Футер лёгкий:** фраза-правило рейтинга («Откройте матч → …») / «Как это работает».

### Mobile

Стек: шапка (бренд + бургер) → sticky-строка лиг (чипы скроллятся по горизонтали, «Все лиги» закреплена справа) → день → «Матч дня» одной карточкой → матчи (плитки П1/Х/П2 под командами во всю ширину) → блок рейла с табами **Таблица / Бомбардиры / Превью** → «Скорострелы» (свёрнуто) → полоса доверия.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading | Скелетон фильтра лиг + списка матчей + правых панелей |
| Empty (нет матчей на дату) | «На эту дату матчей нет» + другой день |
| Тап по «скоро» | Матчи не меняются; toast «Скоро» |
| Нет ни одной активной лиги | «Матчи скоро появятся» — без фейковых матчей |
| Error | «Не удалось загрузить матчи» + «Повторить» |

## Что можно сделать

- Выбрать «Все» или одну/несколько активных лиг чипами или в поповере «Все лиги»; снять лигу повторным кликом или крестиком на доп. чипе.
- Переключить день (вчера / сегодня / завтра) или выбрать дату в календаре месяца.
- Открыть матч → `/matches/{id}`.
- Переключить таблицу / бомбардиров, открыть превью матча, развернуть «Скорострелов».
- Открыть «Как мы считаем», перейти в рейтинг по CTA.
- Перейти в рейтинг, вход, регистрацию, профиль; выйти.

## UX-заметки

- **Общие паттерны референсов (не клонить один сайт):** multi-column IA; навигация по лигам; match-centric колонка; right-rail enrichment; явные active states (разбор: GolStat, Forebet, FotMob, Sofascore, WhoScored).
- **Уникальность MatchIQ:** brand-first; вероятности 0–100 как продукт (П1/Х/П2 крупно, лучшее событие, «Матч дня» с AI-превью); светлый pitch daylight; неактивные лиги «скоро»; CTA рейтинга сдержанный; полоса доверия.
- Данные лиг (`id`, страна, название, short, `status: live | soon`, `sort_order`) с бэка — фронт не хардкодит «только РПЛ». `all` режется до live-лиг; мультивыбор — только live.
- Фильтр — одна строка (не аккордеоны и не большая панель): первый экран отдан матчам.
- Не показываем выдуманные цифры там, где есть данные: без прогноза — «—» и заглушки с пометкой; единственный хардкод — 99% (см. выше).
- Панели рейла — контейнеры данных; не карточный коллаж.

## Заглушки (что заменить)

| Что | Где | Чем заменить |
|-----|-----|--------------|
| hit-rate **99%** | `config/matchiq.php` → `model_hit_rate_placeholder`, `BuildMatchesIndex` (`modelStats`) | реальная метрика по `prediction_outcomes.is_hit`, убрать `is_placeholder` |
| Вероятности П1/Х/П2 | `match_predictions` | пока модель не пишет прогнозы — плитки «—» |
| Лучшие события | `prediction_outcomes` + `market_types.is_popular` | пусто, пока модель не пишет рынки |
| AI-превью в «Матче дня» и рейле | `match_previews` | текст-заглушка / вопрос «кто возьмёт верх?» |
| Логотипы команд | `teams.logo_url` | инициалы, пока ingest не заполняет логотипы |
