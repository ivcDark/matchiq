# Главная / матчи

**URL:** `/`  
**Статус:** MVP  
**Inertia:** `Matches/Index`

## Зачем страница пользователю

Точка входа: за секунды увидеть, какие матчи РПЛ скоро (или уже) и перейти к вероятностям. Страница не «лендинг с маркетингом», а рабочий каталог матчей с коротким объяснением ценности для новичка.

## Что на экране

### Иерархия (сверху вниз)

1. **Шапка:** бренд MatchIQ; ссылки «Рейтинг», «Войти» / «Регистрация» (гость) или «Мои выборы» + выход (авторизованный).
2. **Короткий value-блок (1 строка + подсказка):** например «Вероятности событий по матчам РПЛ» и одна фраза: «Откройте матч → события 0–100 → выберите одно в рейтинг». Без hero-маркетинга, статистики и промо-карточек.
3. **Переключатель периода:** Сегодня / Ближайшие / Завершённые (минимум; по умолчанию — «Ближайшие» или «Сегодня», если есть матчи).
4. **Список матчей** (основной контент):
   - хозяева — гости (или логотипы + короткие имена);
   - дата и время kickoff;
   - статус: ожидается / идёт / завершён;
   - опционально компактно: счёт, если матч идёт или завершён.
5. **Футер лёгкий:** ссылка «Как это работает» (когда страница появится) или та же одна фраза-правило рейтинга.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading | Скелетон списка (3–5 строк), не пустой белый экран |
| Empty (нет матчей за период) | Текст «На этот период матчей нет» + предложить другой период |
| Error | Короткое «Не удалось загрузить матчи» + кнопка «Повторить» |
| Offline / медленная сеть | Тот же error/retry; не зависать на бесконечном спиннере |

## Что можно сделать

- Переключить период (сегодня / ближайшие / завершённые).
- Открыть матч (тап/клик по строке → `/matches/{id}`).
- Перейти в рейтинг, вход, регистрацию, профиль (из шапки).
- Выйти из аккаунта (если авторизован).

## Кто видит

| Роль | Доступ |
|------|--------|
| Гость | Полный просмотр списка; CTA в шапке на вход/регистрацию |
| Авторизованный | То же + ссылка на `/me` |

## UX-заметки

- **Мобильный first:** список на всю ширину, крупные тап-зоны, без плотных таблиц.
- Главная должна **сразу** вести к ценности: матчи видны без скролла длинного intro.
- **Не класть на экран:** таблицу чемпионата, новости, «топ событий сегодня» (пока не доказана польза), сложные виджеты статистики, баннеры, карточный коллаж, несколько конкурирующих CTA.
- Одна лига в MVP (РПЛ) — переключатель лиг не нужен; при мульти-лиге позже — селектор в шапке, не на главном месте.
- Бренд — заметный в шапке; value-блок не перекрикивает бренд длинным заголовком.

## Связи с другими страницами

- → `/matches/{id}` — основной переход.
- → `/leaderboard`, `/login`, `/register`, `/me`.
- ← возврат с матча, 404, auth-страниц («к матчам»).
