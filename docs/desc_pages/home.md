# Главная / матчи

**URL:** `/`  
**Статус:** MVP  
**Inertia:** `Matches/Index`

## Зачем страница пользователю

Точка входа: выбрать турнир или режим **«Все»** (все активные лиги), за секунды увидеть матчи и перейти к вероятностям. Справа — контекст лиги (таблица, бомбардиры) и лёгкий промо-контент. Страница не «лендинг с маркетингом», а рабочий каталог матчей с обогащением.

## Что на экране

### Иерархия (сверху вниз / desktop)

1. **Шапка:** бренд MatchIQ; ссылки «Рейтинг», «Войти» / «Регистрация» (гость) или «Мои выборы» + выход (авторизованный). Опционально — компактный индикатор текущего фильтра лиг.
2. **Короткий value-блок (1 строка + подсказка):** «Вероятности событий по матчам» + «Откройте матч → события 0–100 → выберите одно в рейтинг». Без hero-маркетинга. Справа на desktop — лёгкий reminder «1 событие · 1 матч».
3. **Меню турниров / лиг (выше матчей, обязательный блок):**
   - заметная панель (не тонкая слабая полоска чипов);
   - сверху пункт **«Все»** — матчи всех **live**-лиг (не «скоро»);
   - дальше лиги **сгруппированы по стране** (Россия, Англия, Испания…; UCL — «Европа»): заголовки секций, при большом числе лиг (≥6) — сворачиваемые группы стран (live и страна выбранной лиги открыты по умолчанию);
   - в ячейке: short-код + название (страна уже в заголовке группы);
   - **активные (live)** — кликабельны, фильтруют список матчей; виджеты таблицы/бомбардиров — по выбранной лиге (для «Все» — первая live);
   - **неактивные («скоро»)** — видны, disabled + бейдж «Скоро»; toast «Лига в разработке»;
   - по умолчанию — **«Все»** (`?league=all`); query `league` + `period`;
   - отдельный URL `/leagues` не нужен.
4. **Двухколоночный рабочий блок (desktop ~60–65% / ~35–40%):**
   - **Слева — матчи:**
     - период: Сегодня / Ближайшие / Завершённые (для текущего фильтра лиг);
     - группировка по дате (Сегодня / Завтра / …);
     - строка: время/Live · хозяева — гости · счёт (если есть); в режиме «Все» — короткий код лиги над названием матча;
     - опциональный тизер продукта: топ-исход с вероятностью `%` («открыть события») — без превращения списка в таблицу коэффициентов Forebet.
   - **Справа — виджеты (demo OK):**
     - турнирная таблица выбранной (или top live при «Все») лиги;
     - лучшие бомбардиры лиги;
     - «скорострелы» / топ голов за год (компактный блок, кросс-лига);
     - новости (3–5 карточек) — слот под будущий промо.
5. **Футер лёгкий:** та же фраза-правило рейтинга / «Как это работает».

### Mobile

Стек: шапка → value → меню лиг (страны, при необходимости сворачиваемые) → периоды + матчи → виджеты **табами** (Таблица / Бомбардиры / Скорострелы / Новости) ниже списка.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading | Скелетон меню лиг + списка матчей + правых панелей |
| Empty (нет матчей за период) | «На этот период матчей нет» + другой период |
| Тап по «скоро» | Матчи не меняются; toast «Скоро» |
| Нет ни одной активной лиги | «Матчи скоро появятся» — без фейковых матчей |
| Error | «Не удалось загрузить матчи» + «Повторить» |

## Что можно сделать

- Выбрать «Все» или активную лигу в меню турниров (по странам).
- Переключить период для текущего фильтра.
- Открыть матч → `/matches/{id}`.
- Просмотреть таблицу / бомбардиров / скорострелов / новости (пока demo).
- Перейти в рейтинг, вход, регистрацию, профиль; выйти.

## UX-заметки

- **Общие паттерны референсов (не клонить один сайт):** multi-column IA; навигация по лигам/странам; match-centric колонка; right-rail enrichment; явные active states.
- **Уникальность MatchIQ:** brand-first; вероятности 0–100 как продукт (тизер в строке матча); светлый pitch daylight (не тёмный клон FotMob/GolStat); неактивные лиги «скоро»; CTA рейтинга сдержанный.
- Данные лиг (`id`, страна, название, short, `status: live | soon`) с бэка — фронт не хардкодит «только РПЛ». Фильтр `all` режется до live-лиг на клиенте/бэке.
- Масштаб: не плоская бесконечная лента чипов — секции/аккордеоны по странам.
- Панели виджетов — контейнеры данных/сканирования; не карточный коллаж в hero.
- Бренд заметен в шапке; value-блок не перекрикивает бренд.

## Связи с другими страницами

- → `/matches/{id}` — основной переход.
- → `/leaderboard`, `/login`, `/register`, `/me`.
- ← возврат с матча / auth; желательно сохранять лигу в query/state (`all` или id лиги).
