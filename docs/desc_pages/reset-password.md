# Новый пароль

**URL:** `/reset-password/{token}`  
**Статус:** MVP  
**Inertia:** `Auth/ResetPassword`

## Что на экране

1. Бренд + «Новый пароль».
2. Email · новый пароль · повтор (показать/скрыть, клиентская проверка совпадения).
3. «Сохранить пароль» → `/login` с flash об успехе.

## Состояния

| Состояние | Поведение |
|-----------|-----------|
| Invalid token | Ошибка у email / токена |
| Mismatch | «Пароли не совпадают» |
| Success | Редирект на вход |
