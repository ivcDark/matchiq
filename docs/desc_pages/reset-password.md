# Новый пароль

**URL:** `/reset-password/{token}`  
**Статус:** MVP  
**Inertia:** `Auth/ResetPassword`

## Зачем страница пользователю

Завершить сброс: задать новый пароль по ссылке из письма и снова войти в рейтинг.

## Что на экране

### Иерархия

1. Бренд + заголовок «Новый пароль».
2. **Форма:**
   - email (часто prefilled / hidden из ссылки — по контракту Laravel);
   - новый пароль;
   - подтверждение пароля.
3. Кнопка «Сохранить пароль».
4. Ссылка на `/login`, если токен просрочен — с пояснением.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading | Кнопка disabled |
| Invalid / expired token | «Ссылка устарела» + CTA на `/forgot-password` |
| Validation | Ошибки у полей (несовпадение, слабый пароль) |
| Success | Редирект на `/login` с flash «Пароль обновлён» или автологин (решить в реализации; предпочтительно простой вход) |

## Что можно сделать

- Установить новый пароль.
- Запросить новую ссылку, если эта недействительна.

## Кто видит

| Роль | Доступ |
|------|--------|
| Гость с валидным токеном | Основной сценарий |
| Без токена / битый URL | Сообщение об ошибке + путь к `/forgot-password` |

## UX-заметки

- Минимум текста; фокус на форме.
- **Не класть:** лишние настройки аккаунта на этом экране.

## Связи с другими страницами

- ← письмо с `/forgot-password`.
- → `/login` после успеха.
- → `/forgot-password` при просрочке.
