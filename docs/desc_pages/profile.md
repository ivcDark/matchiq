# Профиль / мои выборы

**URL:** `/me`  
**Статус:** MVP  
**Inertia:** `Profile/Show`  
**Доступ:** только авторизованные (middleware `auth`)

## Зачем страница пользователю

Увидеть свой ник, сумму баллов и историю выбранных событий: что ждал, что зашло, сколько очков начислено. Личная обратная связь по рейтингу без отдельной «соцсети».

## Что на экране

### Иерархия

1. **Шапка** + заголовок «Мои выборы» (или «Профиль»).
2. **Сводка:**
   - ник;
   - сумма баллов;
   - место в рейтинге (если доступно) + ссылка на `/leaderboard`.
3. **Список picks** (новые сверху):
   - матч (хозяева — гости, дата) — ссылка на `/matches/{id}`;
   - выбранное событие / вариант;
   - вероятность модели **на момент выбора** (снимок);
   - статус: ожидает / успех / промах;
   - баллы за этот pick (0 или начисленные).
4. Пустая зона действий: «Выйти» (если нет в шапке); смена ника/пароля — **не здесь** (см. настройки «позже»).

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading | Скелетон сводки + списка |
| Empty picks | «Вы ещё ничего не выбирали» + CTA «К матчам» → `/` |
| Error | Retry |
| Unauthenticated | Редирект на `/login?return=/me` |

## Что можно сделать

- Просмотреть историю picks и статусы.
- Открыть матч из строки.
- Перейти в рейтинг.
- Выйти из аккаунта.
- Вернуться к матчам.

## Кто видит

| Роль | Доступ |
|------|--------|
| Гость | Нет — редирект на вход |
| Авторизованный | Свой профиль только (чужие профили в MVP не публикуем) |

## UX-заметки

- Фокус на списке picks, не на редактировании аккаунта.
- Статусы цветом/меткой, но без шумных бейджей-оверлеев.
- **Не класть:** настройки уведомлений, аватар-аплоад, публичную стену, график Elo.
- Мобильный: карточка-строка на pick (матч + событие + p + статус + очки), без широкой HTML-таблицы.

## Связи с другими страницами

- → `/matches/{id}`, `/leaderboard`, `/`.
- ← после логина с return=/me.
- Позже: → `/settings`.
