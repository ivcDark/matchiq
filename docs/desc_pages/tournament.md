# Страница турнира

**URL:** `/tournaments/{id}` (числовой id; сейчас мок только для РПЛ — `id = 1`)  
**Статус:** MVP (макет на моковых данных)  
**Inertia:** `Tournaments/Show` (контроллер `TournamentController`, моки — `App\Support\MockTournament`)  
**Доступ:** все (гость и авторизованный)

## Зачем страница пользователю

Понять состояние чемпионата перед выбором события: кто в зоне еврокубков и вылета, в какой форме команды, кто забивает, раздаёт передачи и играет надёжнее всех. Данные помогают выбирать события в матчах турнира.

## Что на экране

1. **Ссылка «← Матчи»** → главная.
2. **Шапка турнира:** страна и сезон чемпионата («Россия · Сезон 2026/27»), название («РПЛ»), полное название, стадия («Регулярный чемпионат»), «15 тур из 30» и полоса прогресса.
3. **«Турнирная таблица»:** место, команда, И, В, Н, П, мячи З–П, разница (+/−), очки, форма последних 5 матчей (цветные В / Н / П: зелёный / жёлтый / красный; слева старше, справа свежее). Слева у места цветная полоса **зоны**; под таблицей легенда зон с диапазоном мест. Зоны мока: 1–2 Лига чемпионов, 3–4 Лига Европы, 5 Лига конференций, 13–14 Стыковые матчи, 15–16 Вылет (зоны — демо-разметка, не реальный регламент).
4. **Топ-списки игроков** — шесть блоков (по два в ряд на широком экране, один столбец на мобильном). Первый, третий и четвёртый — **таблицы с сортировкой**, остальные — карточки-списки. В каждой строке: место, `PlayerAvatar` с инициалами, «Фамилия И.» и команда под ником; места 1–3 в золоте / серебре / бронзе (по месту в текущей сортировке).
   - **Таблицы** (`TournamentSortTable.vue`, стиль как у турнирной таблицы): клик по заголовку колонки сортирует по ней, повторный клик меняет направление (стрелка у активной колонки, `aria-sort`); при первом клике числовые колонки идут по убыванию, «Мин/…» — по возрастанию. В таблице показаны 10 первых строк текущей сортировки, поэтому бэкенд отдаёт весь список подходящих игроков.
   - **Лучшие бомбардиры** (таблица): Игрок · **Гол** (пенальти в скобках, например `12 (3)`; без скобок, если пенальти нет) · **Пас** (голевые передачи) · **Г+П**. По умолчанию — Г+П по убыванию. Данные: `goals`, `pens`, `assists`, `ga`.
   - **Самые скорострельные** (таблица): Игрок · **Минут** · **Голов** · **Гол/90** (голов на 90 минут на поле, то есть на полный матч) · Мин/гол (скрыта на мобильном). По умолчанию — Гол/90 по убыванию. Попадают игроки от **600 минут** на поле и минимум с одним голом; порог в заголовке блока.
   - **Лучшие вратари** (таблица): Игрок · **Минут** · **Сухих** (сухие матчи) · **Сух/90** (сухих на 90 минут на поле) · Мин/сух (минут на 1 сухой, скрыта на мобильном). По умолчанию — Сух/90 по убыванию (тот же порядок, что «минут на 1 сухой» по возрастанию). Попадают вратари от **900 минут** и минимум с одним сухим матчем.
   - **Лучшие ассистенты** (карточка, топ-10): передачи; матчи.
   - **Больше всех на поле** (карточка): сыграно минут; матчи.
   - **Лучшие по рейтингу** (карточка): средняя оценка и матчи. Попадают игроки от **8 матчей**.

Сортировка при равенстве: бомбардиры — больше голов, затем меньше минут; ассистенты — меньше минут; «скорострельные» — больше голов; вратари — больше сухих матчей, затем больше минут; минуты — больше матчей; рейтинг — больше матчей. В таблицах при равенстве выбранной колонки сохраняется этот порядок.

## Переходы

Ссылки на турнир есть только там, где у турнира есть страница (поле `tournament_id` в данных лиги: сейчас РПЛ = 1, у остальных лиг `null` — обычный текст без ссылки, мёртвых ссылок нет):

- **Главная, список матчей:** зелёный заголовок группы лиги («РПЛ») — ссылка на `/tournaments/{id}` с мягким hover (160 мс), шевроном справа и фокус-стилем.
- **Главная, правый блок «Таблица»:** подпись справа в шапке («Россия · РПЛ») — ссылка с hover и шевроном (`widgets.league.tournament_id`).
- **Страница матча:** бейдж лиги вверху и название лиги в шапке матча (`match.tournament_id`).
- Пункта «Турниры» в шапке сайта нет; он появится вместе со списком турниров.

## Данные (моки)

`MockTournament::find($id)` возвращает `tournament`, `zones`, `standings`, `leaders` (`scorers`, `assists`, `fastScorers`, `goalkeepers`, `minutes`, `ratings`; у `scorers`, `fastScorers`, `goalkeepers` — полный список для таблиц, у остальных — топ-10) и `thresholds` (`minutes_scoring`, `minutes_goalkeeper`, `matches_rating`). Таблица считается из В / Н / П и мячей: игры, очки (`3·В + Н`), разница и позиции выводятся в коде, итоги сходятся (побед = поражений, забито = пропущено). Игроки вымышленные. Пороги — константы `MockTournament`.

Сезон чемпионата РПЛ (июль — май, «2026/27») считается по дате отдельно и **не совпадает** с сезоном рейтинга платформы (1 августа — 31 июля, см. [leaderboard.md](leaderboard.md)).

## Состояния

| Состояние | Поведение |
|-----------|-----------|
| Неизвестный id или нечисловой сегмент | 404 (общий экран — по [not-found.md](not-found.md)) |
| В списке нет подходящих игроков | «Пока нет игроков, подходящих под условия» |

## Мобильный

Таблица скроллится по горизонтали, колонки «#» и «Команда» закреплены слева; легенда зон переносится на несколько строк; карточки топ-списков в одну колонку.
