# Страница матча

**URL:** `/matches/{id}`  
**Статус:** MVP (ядро продукта) · UI на демо-данных  
**Inertia:** `Matches/Show`

## Зачем страница пользователю

За минуту понять, какие события вероятны в этом матче (оценки модели 0–100), прочитать короткий AI-прогноз хода игры, быстро сравнить команды по стате последних матчей и — при желании — выбрать **одно** событие в рейтинг до старта. Это главный экран MatchIQ: сюда должен попадать почти каждый визит. Плотность блоков — в духе Forebet (прогноз, тренды, тайм/матч), без копирования чужого бренда.

## Что на экране

### Иерархия (сверху вниз)

1. **Назад:** «← Матчи» (+ badge лиги). Возврат на `/` с той же лигой в query (`?league=`), если пришли со списка.
2. **Шапка матча:**
   - хозяева — гости (форма палочками под именами);
   - дата/время старта, **лига** (badge + «страна · название»), тур;
   - статус: ожидается / идёт / завершён (+ счёт, если есть);
   - стадион, судья, **погода** (условие · °C · ветер м/с).
3. **Прогноз исхода** — крупный блок П1 · Н · П2 (% модели) + **возможный счёт** + топ точных счетов.
4. **AI-превью** (2–4 предложения) + **факты/инсайты** (bullet 4–6 пунктов). Подпись «не гарантия».
5. **События (рынки, вид букмекера):**
   - сортировка: **Лучшие** / **Худшие** / **Популярные** — по max % / min % / popular;
   - категории (вторая строка табов, горизонтальный скролл): **Все · Исходы · Тоталы · Голы · Угловые · ЖК · КК**; по умолчанию активна **Исходы** (таб «Все» доступен); в «Все» — группы с заголовками; в конкретной категории — только её рынки; сортировка применяется внутри;
   - у рынка поле `category`; счётчики в табах по желанию;
   - рынок = карточка с **группой исходов**: «Исход матча» → П1 | Н | П2; «Тотал 2.5» → ТБ | ТМ; «Обе забьют» → Да | Нет;
   - вместо коэффициентов БК — **проценты ИИ 0–100**; пары суммируются в 100, 1X2 = 100;
   - у исхода: лейбл · крупный % · «выбрали N%» · CTA «Выбрать» / «Выбрано» (**один** исход на матч);
   - подсказка рейтинга; гость при «Выбрать» — CTA на `/login` / `/register`.
6. **Тренды и серии** — для обеих команд: забьёт (серия), сухие, Обе забьют, ТБ 2.5, ТМ 2.5 (последние 5).
7. **Голы · тайм/матч · таймы** — средние ЗП/ПР/тотал по командам, ожидаемый тотал матча; сетка «тайм / матч» % (комбинации `1/Н/2`, легенда под блоком); тоталы **ТБ 0.5 (1+ гол)** / **ТБ 1.5 (2+ гола)** и ср. голы по половинам.
8. **Последние 5 матчей** — один блок сравнения с переключателями:
   - период: **Матч · 1-й тайм · 2-й тайм** (mock на 3 периода);
   - вид: **Шкалы** (дефолт, иконка столбиков) — шкалы + справа круги только для %-метрик; **Круги** (иконка pie) — все метрики кругами (секторы хозяева/гости); tooltip «Шкалы, проценты кругами» / «Все показатели кругами»;
   - цвета **команд**, тёплые (sage / terracotta), не cold teal;
   - шкалы от **номинальной нормы** (`scale` метрики), чтобы видна заполненность; в шапке: «цвета команд · шкала от нормы».
   Метрики: голы, xG, удары, в створ, угловые, жёлтые, фолы, владение %, Обе забьют %, сухие %.
9. **Дома / в гостях** (extra из ресёрча): средние забито/пропущено/xG/угловые + ЖК, удары в створ, фолы, офсайды; переключатель выборки **В турнире / 5 матчей / 10 матчей** (mock на 3 набора).
10. **Статистика судьи** (сезон с начала): имя и страна/город из шапки матча; табы **Все / РПЛ / Кубок России** (три демо-набора); плитки **Матчи · ЖК · КК · ЖК/матч · КК/матч** (жёлтая/красная иконка-карточка у ЖК/КК); при малом числе матчей в выборке — прочерки; блок перед мини-таблицей, на mobile плитки в колонку.
11. **Мини-таблица** лиги: колонки **И, В, Н, ЗП, ПР, +/−, О, О/И, Форма**; форма — 5 цветных плашек **В/Н/П** (зелёный / янтарный / красный; слева старше, справа свежее); подсветка обеих команд матча (+ соседние места). Не дублирует карточки формы ниже.
12. **Бомбардиры** — две таблицы (хозяева / гости; рядом на desktop, стек на mobile), топ-5 игроков:
    столбцы **Игрок · Гол · ПАС · Пен · Г+ПАС** (Пен входит в Гол; Г+ПАС = Гол+ПАС); сортировка по Г+ПАС ↓;
    в шапке только текст (без иконок); tooltip: «ПАС — голевые передачи», «Г+ПАС — голы + голевые передачи»;
    числа `tabular-nums` вправо; лидер колонки мягко подсвечен; шапка с `title`-расшифровками.
13. **Лучшие игроки** — две карточки (хозяева / гости; рядом на desktop, стек на mobile) сразу после бомбардиров:
    аватар (`PlayerAvatar`, fallback инициалы при пустом `photo_url`); имя **Фамилия И.**; позиция и номер мелко;
    бейдж средней оценки (зелёный ≥7.5, жёлтый ≥6.5, красный ниже); ряд **Матчи · Голы · ПАС · ЖК**
    с иконками (`MatchStatIcon`: календарь / футбольный мяч / бутса с мячом / жёлтая карточка как у судьи);
    заголовок карточки цветом команды. Демо: `bestPlayers.home|away`.
14. **Потери** — травмы / дисквалификации / сомнительные.
15. **Голы по минутам** — один блок, две секции с общей шкалой:
    - **· забитые** — сколько голов забито командой в каждом 15-минутном отрезке (0–15 … 75–90);
    - **· пропущенные** — то же для пропущенных голов;
    - вертикальные пары столбцов, цвета команд, числа под столбцами; высота от общей нормы `scale` (сопоставимо между секциями);
    - в каждой секции отдельно подсвечен **максимум** хозяев и гостей (насыщеннее + обводка/свечение, жирное число; при ничьей — все пики);
    - под секцией строка-вывод: «Чаще всего забивает / пропускает: интервал (команда), …».
16. **Форма** — 5 карточек последних 5: очные встречи; хозяева; гости; хозяева дома; гости в гостях.
    - строка: дата · хозяева **[плашка FT]** гости · метка турнира; плашка залита цветом результата для focus-команды (зелёный / янтарный / красный), белый счёт; под FT мелко HT в скобках;
    - зебра строк; focus-команда жирным (в H2H — хозяева текущего матча);
    - чипы фильтра турнира в шапке карточки (**Все** + турниры из данных);
    - внизу сводка: сегментная полоса В/Н/П и три колонки «Победы / Ничьи / Поражения» (N / %).
17. **Комментарии** — демо-тред; гостю — CTA войти, чтобы писать.

### Live и завершённые матчи (match center)

Для `status = live | finished` под шапкой появляется подменю, предстоящие матчи (`scheduled`) выглядят как раньше — полный набор блоков 1–17 без вкладок (`matchCenter = null`).

| Вкладка | Содержимое |
|---------|------------|
| **Сводка** (по умолчанию) | **Хроника**: минута по центру, события хозяев слева, гостей справа (гол + счёт + ассист «А», жёлтая/красная, замены ↑ вышел / ↓ ушёл); **Лучшие игроки матча** (только `finished`; у `live` блока нет, `best_players = null`) — две колонки, топ-3 с рейтингом (зелёный ≥7.5, янтарный ≥6.5, красный ниже; у вышедших с замены `▲ минута`); **Составы команд** (идут перед расстановкой) — две колонки (стек на mobile): общие вкладки **«Стартовый состав»** / **«Запасные»** (со счётчиками; переключают списки сразу в обеих колонках; по умолчанию — старт); шапка команды с формацией; **Стартовый состав** (11: номер, имя, амплуа ВРТ/ЗАЩ/ПЗ/НАП, ▼ минута ухода, карточка), **Запасные** (7: номер, имя, амплуа, ▲ минута выхода у вышедших); **Тренер** всегда внизу колонки, вне вкладок; **Расстановка на поле** (блок «Составы» под составами команд) — схема двух команд на одном поле (хозяева сверху, гости снизу, формация по линиям, номера, имена, значки гол / ассист / карточка / замена). **Оценки игроков и команды — только у `finished`** (зелёный ≥7.5, янтарный ≥6.5, красный ниже); у `live` рейтинг-бейджей нет, `rating = null`. **Лучший игрок матча (MOTM)** — **жёлтая звезда ★** рядом с одним игроком с максимальным рейтингом среди обеих команд (старт и вышедшие со скамейки; при равенстве — хозяин, затем более ранний в списке): в «Лучших игроках матча» (у имени перед рейтингом), в «Составах команд» (после имени, в «Стартовом составе» или «Запасных») и на «Расстановке» (над номером). Только `finished`; у `live` звезды нет. Источник правды — флаг `motm` у игрока в `MockMatchCenter` (`lineups.*.players/bench/substitutes`, `best_players.*`). |
| **Статистика** | Переключатель периода (`.miq-mc-tabs`): **Весь матч** (по умолчанию) · **1 тайм** · **2 тайм**; счётчики матча = сумма таймов, проценты и владение считаются по периоду отдельно. У live 2 тайм доступен после 45′ (данные до 63′); до перерыва вкладка disabled с подсказкой «Тайм ещё не начался». Двусторонние ряды `хозяева · метрика · гости`, секции: Ожидаемые очки, Атака · xG, Защита · xG, Стандарты · xG, Атака, Удары, Передачи, Защита (слева xG и передачи, справа атака, удары, защита). Лучшее значение подсвечено (хозяева — sage, гости — coral); для xGA, офсайдов, фолов, карточек, мимо/заблокированных ударов лучше **меньшее**; равенство и нейтральные ряды без подсветки; нет данных — «–» |
| **Прогноз** | Только три блока: **Прогноз исхода** (П1 · Н · П2, возможный счёт, топ точных счетов), **Краткий прогноз модели** (превью + факты), **События** (рынки с % ИИ и выбором исхода; отметки «зашло / мимо» в центре матча не показываем). Тренды, тайм/матч, сравнение, дома/в гостях, судья, таблица, бомбардиры, лучшие игроки, потери, голы по минутам и форма здесь **не** выводятся (остаются у `scheduled`) |

- Шапка: у live счёт цветом live и мигающая минута (`match.minute`), у finished — финальный счёт и «Матч завершён».
- Комментарии остаются внизу при любой вкладке.
- Props: `match.status`, `match.minute` (только live), `matchCenter: { minute, events[], stats{match,first_half,second_half}, best_players{home,away}|null (null у live), lineups{home,away} }`.
  - `events[]`: `{ minute, side, type: goal|yellow|red|sub, player, assist?, player_in?, player_out?, score_home?, score_away? }`, отсортированы по минуте;
  - `stats`: `{ match, first_half, second_half|null }` (`second_half = null`, пока 2 тайм не начался); каждый период — `[{ id, title, column: left|right, rows: [{ id, label, home, away, fmt: int|dec|pct|signed, better: high|low|null, hint }] }]`;
  - `lineups.{side}`: `{ formation, rating (null у live), coach, players[11: GK первым, далее по линиям], bench[вышедшие], substitutes[7 запасных: { number, name, line, sub_in? }] }`, игрок: `{ number, name, line, rating (null у live), goals, assists, yellow, red, sub_out, sub_in }`.
- Источник — детерминированный мок `App\Support\MockMatchCenter` (от id и счёта): голы в хронике = счёт, сейвы = удары в створ соперника − пропущенные, у live всё режется минутой (63') и масштабируется. Без API и polling.
- Демо: **live** — `/matches/102` (ЦСКА 1∶1 Динамо, 63'); **finished** — `/matches/109`, `/matches/106`, `/matches/107` (красная карточка), `/matches/203`. Остальные id (в т.ч. `/matches/101`) — предстоящие.

### Состояния матча

| Статус матча | Вероятности | Pick |
|--------------|-------------|------|
| Ещё не начался | Актуальный снимок (может обновляться до kickoff) | Можно выбрать / заменить |
| Идёт | Read-only снимок на момент kickoff | Закрыт |
| Завершён | Снимок + отметка «зашло / мимо» у событий | Закрыт; у пользователя — результат его pick |

### Состояния UI

| Состояние | Поведение |
|-----------|-----------|
| Loading | Скелетон шапки + 4–6 строк событий |
| Empty (модель ещё не посчитала) | «Вероятности пока считаются»; без фейковых чисел |
| AI-текст отсутствует | Скрыть блок |
| Error | «Не удалось загрузить матч» + «Повторить» + ссылка на `/` |
| 404 матча | Как [not-found](not-found.md) или inline «Матч не найден» |
| Уже есть pick | Подсветка выбранного события; до kickoff можно заменить |
| После резолва | У выбранного: успех / промах + баллы (когда появится бэкенд) |

## Что можно сделать

- Вернуться к списку матчей (с сохранением лиги в query).
- Переключить фильтр событий (лучшие / худшие / популярные).
- **Авторизованный, до kickoff:** выбрать одно событие в рейтинг; **заменить** до старта.
- **Гость:** смотреть всё; при выборе — CTA на `/login` (с возвратом на этот матч — позже через intended URL).
- Перейти в рейтинг / профиль / регистрацию из шапки.

## Кто видит

| Роль | Доступ |
|------|--------|
| Гость | Полный просмотр вероятностей, статы и AI-текста; pick недоступен без входа |
| Авторизованный | + действие выбора / замены до kickoff; видит свой текущий pick |

## UX-заметки

- **Mobile-first, scannable comparison** — не data dump: крупные %, короткие названия, dual bars вместо таблиц аналитика.
- На исходе — **только вероятность** (+ compact popular %), без блока «почему» и без фактор-листов; макет рынка как у БК.
- Экран **общий для всех лиг**: один шаблон; лига — метаданные/badge в шапке.
- Не обещать «гарантию»; вероятности — оценка модели.
- После kickoff UI не «сломан» — явно «выбор закрыт».
- Визуал: pitch-green + Syne (заголовки/бренд) / Manrope (UI); крупные цифры — класс `.num-display` (Manrope + lining/tabular nums); `AppLayout`, те же `miq-*` панели/анимации, что на главной; тёплые team colors.
