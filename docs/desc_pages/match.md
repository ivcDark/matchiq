# Страница матча

**URL:** `/matches/{id}`  
**Статус:** MVP (ядро продукта) · UI на демо-данных  
**Inertia:** `Matches/Show`

## Зачем страница пользователю

За минуту понять, какие события вероятны в этом матче (оценки модели 0–100), прочитать короткий AI-прогноз хода игры, быстро сравнить команды по стате последних матчей и — при желании — выбрать **одно** событие в рейтинг до старта. Это главный экран MatchIQ: сюда должен попадать почти каждый визит. Плотность блоков — в духе Forebet (прогноз, тренды, тайм/матч), без копирования чужого бренда.

## Что на экране

### Иерархия (сверху вниз)

1. **Назад:** «← Матчи» (+ badge лиги). Возврат на `/` с той же лигой в query (`?league=`), если пришли со списка.
2. **Шапка матча:**
   - хозяева — гости (форма палочками под именами);
   - дата/время старта, **лига** (badge + «страна · название»), тур;
   - статус: ожидается / идёт / завершён (+ счёт, если есть);
   - стадион, судья, **погода** (условие · °C · ветер м/с).
3. **Прогноз исхода** — крупный блок П1 · Н · П2 (% модели) + **возможный счёт** + топ точных счетов.
4. **AI-превью** (2–4 предложения) + **факты/инсайты** (bullet 4–6 пунктов). Подпись «не гарантия».
5. **События (рынки, вид букмекера):**
   - фильтры (один активный): **Лучшие** / **Худшие** / **Популярные** — сортируют **рынки** по max % / min % / popular;
   - рынок = карточка/строка с **группой исходов** (не длинный список одиночных строк): например «Исход матча» → П1 | Н | П2; «Тотал 2.5» → ТБ | ТМ; «Обе забьют» → Да | Нет;
   - вместо коэффициентов БК — **проценты ИИ 0–100**; противоположные исходы согласованы (ТБ + ТМ = 100, Да + Нет = 100, П1+X+П2 = 100);
   - у исхода: лейбл · крупный % · компактно «выбрали N%» · CTA «Выбрать» / «Выбрано» (**один** исход на матч);
   - подсказка рейтинга: «1 исход на матч · больше баллов за смелый верный выбор»;
   - гость при клике «Выбрать» — мягкий CTA на `/login` / `/register` (без фейкового выбора).
6. **Тренды и серии** — для обеих команд: забьёт (серия), сухие, Обе забьют, ТБ 2.5, ТМ 2.5 (последние 5).
7. **Голы · тайм/матч · таймы** — средние ЗП/ПР/тотал по командам, ожидаемый тотал матча; сетка «тайм / матч» % (комбинации `1/Н/2`, легенда под блоком); тоталы **ТБ 0.5 (1+ гол)** / **ТБ 1.5 (2+ гола)** и ср. голы по половинам.
8. **Последние 5 матчей** — один блок сравнения с переключателями:
   - период: **Матч · 1-й тайм · 2-й тайм** (mock на 3 периода);
   - вид: **Шкалы** (дефолт, иконка столбиков) — шкалы + справа круги только для %-метрик; **Круги** (иконка pie) — все метрики кругами (секторы хозяева/гости); tooltip «Шкалы, проценты кругами» / «Все показатели кругами»;
   - цвета **команд**, тёплые (sage / terracotta), не cold teal;
   - шкалы от **номинальной нормы** (`scale` метрики), чтобы видна заполненность; в шапке: «цвета команд · шкала от нормы».
   Метрики: голы, xG, удары, в створ, угловые, жёлтые, фолы, владение %, Обе забьют %, сухие %.
9. **Дома / в гостях** (extra из ресёрча): средние забито/пропущено/xG/угловые + ЖК, удары в створ, фолы, офсайды; переключатель выборки **В турнире / 5 матчей / 10 матчей** (mock на 3 набора).
10. **Мини-таблица** лиги: колонки **И, В, Н, ЗП, ПР, +/−, О, О/И, Ф** (форма · последние 5 компактно); подсветка обеих команд матча (+ соседние места). Не дублирует карточки формы ниже.
11. **Бомбардиры** каждой команды (голы + передачи).
12. **Потери** — травмы / дисквалификации / сомнительные.
13. **Голы по минутам** — вертикальные пары столбцов (интервалы на оси, цвета команд); **суммы** голов по отрезкам 0–15 … 75–90, высота от номинальной шкалы `scale`.
14. **Форма** — 5 карточек последних 5: очные встречи; хозяева; гости; хозяева дома; гости в гостях. На матч: дата, пары, счёт, П/Н/Пр.
15. **Комментарии** — демо-тред; гостю — CTA войти, чтобы писать.

### Состояния матча

| Статус матча | Вероятности | Pick |
|--------------|-------------|------|
| Ещё не начался | Актуальный снимок (может обновляться до kickoff) | Можно выбрать / заменить |
| Идёт | Read-only снимок на момент kickoff | Закрыт |
| Завершён | Снимок + отметка «зашло / мимо» у событий | Закрыт; у пользователя — результат его pick |

### Состояния UI

| Состояние | Поведение |
|-----------|-----------|
| Loading | Скелетон шапки + 4–6 строк событий |
| Empty (модель ещё не посчитала) | «Вероятности пока считаются»; без фейковых чисел |
| AI-текст отсутствует | Скрыть блок |
| Error | «Не удалось загрузить матч» + «Повторить» + ссылка на `/` |
| 404 матча | Как [not-found](not-found.md) или inline «Матч не найден» |
| Уже есть pick | Подсветка выбранного события; до kickoff можно заменить |
| После резолва | У выбранного: успех / промах + баллы (когда появится бэкенд) |

## Что можно сделать

- Вернуться к списку матчей (с сохранением лиги в query).
- Переключить фильтр событий (лучшие / худшие / популярные).
- **Авторизованный, до kickoff:** выбрать одно событие в рейтинг; **заменить** до старта.
- **Гость:** смотреть всё; при выборе — CTA на `/login` (с возвратом на этот матч — позже через intended URL).
- Перейти в рейтинг / профиль / регистрацию из шапки.

## Кто видит

| Роль | Доступ |
|------|--------|
| Гость | Полный просмотр вероятностей, статы и AI-текста; pick недоступен без входа |
| Авторизованный | + действие выбора / замены до kickoff; видит свой текущий pick |

## UX-заметки

- **Mobile-first, scannable comparison** — не data dump: крупные %, короткие названия, dual bars вместо таблиц аналитика.
- На исходе — **только вероятность** (+ compact popular %), без блока «почему» и без фактор-листов; макет рынка как у БК.
- Экран **общий для всех лиг**: один шаблон; лига — метаданные/badge в шапке.
- Не обещать «гарантию»; вероятности — оценка модели.
- После kickoff UI не «сломан» — явно «выбор закрыт».
- Визуал: pitch-green + Syne/Manrope, `AppLayout`, те же `miq-*` панели/анимации, что на главной; тёплые team colors.

## Демо сейчас

- Богатый пакет для матчей из списка (эталон: Зенит — Спартак `/matches/101`).
- `markets[]` в Inertia: `{ id, name, popular_pct, outcomes: [{ id, label, prob, popular_pct, hit }] }` — % внутри рынка суммируются в 100.
- Доп. props: `forecast`, `insights`, `trends`, `goalProfile`, `formBlocks`; у `match.weather` — погода.
- Pick на клиенте локально для авторизованных (без персистенции); гость — только CTA.
- Комментарии и стата — demo seed в `MatchController`.
