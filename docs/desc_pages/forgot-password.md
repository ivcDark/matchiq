# Забыли пароль

**URL:** `/forgot-password`  
**Статус:** MVP  
**Inertia:** `Auth/ForgotPassword`

## Зачем страница пользователю

Запросить ссылку для сброса пароля, если вход недоступен. Простой служебный поток — без трения.

## Что на экране

### Иерархия

1. Бренд + заголовок «Сброс пароля».
2. Короткая инструкция: «Укажите email — пришлём ссылку».
3. Поле email + кнопка «Отправить ссылку».
4. Ссылка «Назад ко входу» → `/login`.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading | Кнопка disabled |
| Success | Нейтральное «Если аккаунт существует, письмо отправлено» (без enumeration) |
| Validation / rate limit | Сообщение у поля или общее |
| Error (почта недоступна) | Честное «Сейчас не удалось отправить» + retry |

## Что можно сделать

- Запросить письмо со ссылкой.
- Вернуться ко входу / к матчам.

## Кто видит

| Роль | Доступ |
|------|--------|
| Гость | Страница доступна |
| Авторизованный | Обычно редирект на `/` (смена пароля из настроек — позже) |

## UX-заметки

- Один экран, одно действие.
- **Не класть:** вопросы безопасности, капчу без нужды, лишние поля.
- Письмо ведёт на `/reset-password/{token}`.

## Связи с другими страницами

- ← `/login`.
- → `/reset-password/{token}` (из письма).
- → `/`.
