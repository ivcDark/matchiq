# Страница 404

**URL:** любой неизвестный маршрут (Inertia/Laravel error page)  
**Статус:** MVP  
**Inertia:** `Error` / `NotFound` (или общая error page со status 404)

## Зачем страница пользователю

Понятно сообщить, что адрес не найден, и быстро вернуть к матчам — без «технического» тупика.

## Что на экране

### Иерархия

1. Бренд MatchIQ.
2. Короткий текст: «Страница не найдена».
3. Одна кнопка/ссылка: «К матчам» → `/`.
4. Опционально: ссылка на рейтинг.

### Состояния

Единственное целевое состояние — 404. Для 500 — отдельное короткое «Что-то сломалось» + «На главную» (можно тот же layout с другим текстом; детали не раздувать).

## Что можно сделать

- Перейти на главную / рейтинг.

## Кто видит

Все (гость и авторизованный).

## UX-заметки

- Минимум текста, без шуток на полэкрана и без поисковой формы в MVP.
- **Не класть:** карту сайта, длинный FAQ, иллюстрации ради иллюстраций, если они мешают CTA.

## Связи с другими страницами

- → `/`, опционально `/leaderboard`.
