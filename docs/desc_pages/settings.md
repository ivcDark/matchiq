# Настройки аккаунта

**URL:** `/settings`  
**Статус:** **позже**  
**Inertia:** `Settings/Edit` (черновик)  
**Доступ:** авторизованные

## Зачем страница пользователю

Позже: сменить ник, email или пароль без обращения в поддержку. В MVP достаточно регистрации/сброса пароля по email; профиль `/me` не смешиваем с формой настроек.

## Что на экране (черновик)

1. Секции: ник; email; пароль (текущий + новый).
2. Сохранение по секциям или одна кнопка — решить при дизайне.
3. Ссылка назад на `/me`.

### Состояния

Validation на месте; success flash; unauthorized → login.

## Что можно сделать

- Обновить данные аккаунта.
- Вернуться к picks.

## Кто видит

Только владелец аккаунта.

## UX-заметки

- Простые формы, без «центра уведомлений» и privacy-матриц в первой версии настроек.
- **Не класть в MVP-профиль:** эти поля — отдельный экран, когда понадобится.

## Связи с другими страницами

- ← `/me`.
- → `/login` при истечении сессии.
- Сброс пароля без входа остаётся на `/forgot-password`.
