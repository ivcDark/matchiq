# Страница клуба

**URL:** `/clubs/{id}` (числовой id 1–16, route name `clubs.show`; неизвестный или нечисловой id → 404)  
**Статус:** MVP (макет на моковых данных; готова только вкладка «Сводка»)  
**Inertia:** `Clubs/Show` (контроллер `ClubController`, моки — `App\Support\MockClub`, считает на основе `MockTournament`)  
**Доступ:** все (гость и авторизованный)

> Выбран `/clubs/{id}`, а не `/teams/{id}`. Старый черновик [team.md](team.md) заменён этой страницей: URL `/teams/{id}` не используется.

## Зачем страница пользователю

Быстро понять контекст клуба перед выбором события: где команда в таблице РПЛ и на каком этапе Кубка России, как она играет дома и в гостях, кто забивает и отдаёт передачи, как часто в её матчах бывает тотал больше или обе забьют.

## Вход

- **Турнирная таблица** (`TournamentStandings.vue`) и таблица формы (`TournamentForm.vue`): название клуба — ссылка на `/clubs/{team_id}`. У всех 16 команд есть `team_id`.
- **Страница матча** (`Matches/Show.vue`): названия хозяев и гостей в шапке — ссылки на клуб (`match.home_club_id` / `match.away_club_id`). Если клуба нет в моках, имя остаётся обычным текстом.

## Что на экране

1. **← Турнирная таблица** → `/tournaments/{tournament_id}#standings`.
2. **Компактная шапка** (одна панель, без hero): страна · город, название клуба, справа место в РПЛ, очки и сезон.
3. **Подменю секций** (`TournamentSectionNav`, как на турнире): **Сводка** (по умолчанию) · Календарь · Результаты · Статистика. Выбор синхронизируется с хешем URL (`#calendar`, `#results`, `#stats`; для Сводки хеш пустой), перезагрузки нет.

### Сводка

1. **Место в таблице РПЛ** (`ClubStandingSpot`): позиция, очки, И/В/Н/П, разница мячей и пять строк вокруг клуба (текущий выделен). Данные берутся из той же турнирной таблицы.
2. **Кубок России** (`ClubCupStatus`): стадия (групповой этап), группа A–D, мини-таблица группы из 4 команд, зона плей-офф (первые две), ближайший матч кубка. Мок: 4 группы по 4 команды, двухкруговой турнир из 6 туров, сыграно 4.
3. **Панель фильтров**: «Матчи» — **В целом / Хозяева / Гости** (`TournamentContextTabs`), меняет числа во всех блоках ниже. **Выбор турнира** вынесен в шапки блоков **Голы**, **Лучшие игроки** и **Игроки**: живой сегмент-переключатель `ClubTournamentSwitch` из трёх кнопок **РПЛ · Кубок России · Все матчи** (ключи `rpl` / `cup` / `all`, активная подсвечена, `aria-pressed`). Состояние одно (`tournament` в `Clubs/Show`): три переключателя связаны через `v-model`, переключение в любом меняет сразу все три блока (мок: `goals.{rpl,cup,all}`, `players.{rpl,cup,all}`). Переключатель передаётся в блоки слотом `controls` шапки. Серая подпись venue рядом с переключателем теперь не дублирует «все матчи»: для «В целом» подписи нет, для фильтров показывается «только дома» / «только в гостях» (то же у таблицы «Статистика по турнирам»). «Статистика по турнирам» от выбора турнира не зависит — в ней обе строки сразу.

   **«Все матчи» = РПЛ + Кубок России** (`MockClub::ALL_KEY`, согласовано с итоговой строкой «Всего / среднее» таблицы «Статистика по турнирам» в том же фильтре В целом/Хозяева/Гости):
   - **Голы:** матчи РПЛ и Кубка объединяются в один список, затем те же формулы — матчи, забито и пропущено суммируются, «за матч» = сумма / матчи, каждый рынок (тоталы, обе забьют, сухой матч, открыли счёт) = сумма по двум турнирам, проценты пересчитываются от общего числа матчей. Итоги совпадают с `stats.*.total` (матчи, голы, пропущено).
   - **Игроки (Лучшие игроки, Игроки):** по каждому игроку складываются выходы, старты, замены, минуты, голы, передачи, ЖК, КК, ЛИМ; удары, пасы %, воздух и рейтинг за матч — среднее с весом по числу выходов в каждом турнире. Игрок, не выходивший в срезе, скрывается. Сумма голов игроков = голы команды в итоговой строке.
4. **Статистика по турнирам** (`ClubTournamentStats`, как `stats-summary`): строки РПЛ и Кубок, колонки — матчи, голы (забито/пропущено), удары за матч, ЖК/КК, владение %, точность пасов %, воздух, рейтинг; итоговая строка (суммы и средние). Фильтр «В целом/Хозяева/Гости» пересчитывает строки.
5. **Голы** (`ClubGoalsSplit`, как `goals-split-bars`): забито и пропущено (всего и за матч) и полосы по рынкам: тотал меньше/больше 1.5, 2.5, 3.5; обе забьют да/нет; сухой матч; **«Открыли счёт»** да/нет — в скольких матчах клуб забил первым (в моках минут первого гола нет, исход выводится детерминированно из результата: 0 забитых — нет, 0 пропущенных — да, иначе по хэшу матча: победа ~70%, ничья 50%, поражение ~30%). Сумма двух сторон каждой полосы = 100%.
6. **Лучшие игроки** (`ClubBestPlayers`, как `best-players`): сетка топ-5 — голы, агрессия (ЖК/КК), выходы, воздух, передачи, рейтинг, с полосами значений.
7. **Игроки** (`ClubPlayersTable`, как `players-summary`): возраст, позиция, рост, вес, выходы, минуты, голы, передачи, ЖК, КК, удары за игру, точность пасов, воздух, лучший игрок матча, рейтинг. Сортировка по умолчанию по рейтингу.

### Календарь · Результаты · Статистика

Заглушки: пункт меню и короткий текст «появится позже». Содержимое опишет продукт отдельно.

## Моки и согласованность

- Все числа выводятся из `MockTournament` (первый круг РПЛ, 15 туров), поэтому совпадают с турнирной таблицей и страницей турнира.
- Для 16 клубов используется одна структура; цифры различаются детерминированно (`crc32` от названия клуба), без случайности между запросами.
- Инварианты (проверяются тестами): голы игроков = голы команды в каждом фильтре; Хозяева + Гости = В целом; голы и позиция совпадают с таблицей; группы кубка по 4 команды.
- `MockClub::TEAMS` — id → название. Новый клуб должен получить id здесь, чтобы ссылки из таблицы работали.

## Состояния

404 для неизвестного клуба. Пустых состояний нет: у всех клубов есть игроки и матчи в моках.

## Что можно сделать

- Переключить фильтр матчей и турнир (РПЛ, Кубок России, Все матчи), посмотреть, как меняются цифры.
- Перейти в турнирную таблицу.
- Вернуться на клуб из таблицы и матча.

## UX-заметки

- Стиль MatchIQ (mist/chalk, sage/coral): светлые шапки таблиц, без чёрных заголовков и бейджей «NEW». Плотные таблицы с горизонтальной прокруткой на мобильном.
- Не превращать в профиль клуба как у Transfermarkt: составы на весь экран, трансферы и страница игрока не входят.

## Не сделано

- Содержимое вкладок Календарь, Результаты, Статистика.
- Страница игрока.
- Реальные данные вместо моков, настоящий Кубок России.
- Ссылки на клуб из других мест (например, из топ-листов турнира).
