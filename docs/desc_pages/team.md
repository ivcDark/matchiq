# Страница команды

**URL:** `/teams/{id}`  
**Статус:** заменена страницей клуба, см. [club.md](club.md) (`/clubs/{id}`)  
**Inertia:** `Teams/Show` (черновик)

## Зачем страница пользователю

Позже: узнать контекст клуба и быстро открыть его ближайшие матчи с вероятностями. В MVP команды — только имена на списке/матче, без отдельного хаба.

## Что на экране (черновик)

1. Название / эмблема клуба, лига / страна (клуб может участвовать в турнирах; в MVP достаточно основной лиги).
2. Ближайшие и недавние матчи → `/matches/{id}` (в контексте своей лиги).
3. Позже: простая форма/краткая стата — без аналитических дашбордов.

### Состояния

Loading / empty (нет матчей) / 404 команды — по аналогии с матчем.

## Что можно сделать

- Открыть матч команды.
- Вернуться к списку матчей.

## Кто видит

Все (публичная страница).

## UX-заметки

- Не превращать в «профиль клуба как у Transfermarkt».
- **Не в MVP:** составы на весь экран, страница игрока, трансферы.

## Связи с другими страницами

- ← клик по названию команды на `/matches/{id}` (когда включим).
- → `/matches/{id}`, `/`.
