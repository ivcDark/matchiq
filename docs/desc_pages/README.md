# MatchIQ — описание страниц (MVP)

**Назначение:** спецификации экранов для дизайна и реализации (Inertia/Vue).  
**Стек:** Laravel + Vue + Inertia.  
**Лиги:** продукт рассчитан на **много лиг/турниров по странам**. РПЛ — **первая живая лига** для триала; остальные топ-лиги показываем как неактивные («скоро»), пока не подключим. Лиги добавляем постепенно.  
**Язык UI в спецификациях:** русский (язык продукта MVP ещё открыт; тексты ниже — рабочие).

## IA: гость vs авторизованный

```
Гость                          Авторизованный
─────                          ──────────────
/ → лиги + список матчей       / → лиги + список матчей
  └→ /matches/{id}               └→ /matches/{id}
       смотрит вероятности            смотрит + выбирает 1 событие
       CTA «войти для рейтинга»       (до kickoff; можно заменить)
  └→ /leaderboard (read-only)    └→ /leaderboard (+ своя строка)
  └→ /login | /register          └→ /me (picks + баллы)
                                 └→ logout
```

**Правило доступа:** гости видят матчи, вероятности и рейтинг; **участвовать в рейтинге** (сделать pick) — только после входа/регистрации.

## IA: лиги (мульти-лига)

```
Главная `/`
  ├─ Переключатель / пикер лиг (по странам)
  │    ├─ Активные (live)     → кликабельны; список матчей этой лиги
  │    └─ «Скоро» (in progress) → видны, disabled; не ведут в матчи
  └─ Матчи выбранной активной лиги → /matches/{id}
```

- **Сейчас для триала:** активна РПЛ; топ 5–10 других лиг — placeholders «скоро».
- **Дальше:** включаем лиги по одной; IA и URL матчей уже не завязаны на одну лигу.
- URL матча остаётся `/matches/{id}` (лига — атрибут матча, не отдельный раздел URL в MVP).

## Принципы навигации

1. Главный путь: **лиги → матчи → матч**. Рейтинг и профиль — вторичны.
2. Первый визит должен за минуту дойти до ценности на странице матча (события + 0–100).
3. На главной и матче — короткие подсказки «как это работает» inline; отдельный FAQ — позже.
4. Мобильный first; минимум кликов до вероятностей.
5. Вне MVP (не описываем отдельными файлами): страница игрока, таблица лиги, админка, live-таймлайн, отдельный каталог `/leagues`.
