# Вход

**URL:** `/login`  
**Статус:** MVP  
**Inertia:** `Auth/Login`

## Зачем страница пользователю

Вернуться в аккаунт, чтобы продолжить picks и видеть свой прогресс в рейтинге.

## Что на экране

### Иерархия

1. Бренд + заголовок «Вход».
2. **Форма:**
   - email;
   - пароль;
   - опционально «Запомнить меня».
3. Кнопка «Войти».
4. Ссылка «Забыли пароль?» → `/forgot-password`.
5. Ссылка «Нет аккаунта? Регистрация» → `/register`.
6. Ссылка «К матчам» → `/`.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading (submit) | Кнопка disabled |
| Неверные данные | Сообщение без утечки «существует ли email» сверх необходимого Laravel |
| Validation | Ошибки у полей |
| Success | Редирект на `return` URL или `/` |

## Что можно сделать

- Войти.
- Перейти к регистрации / сбросу пароля / списку матчей.

## Кто видит

| Роль | Доступ |
|------|--------|
| Гость | Страница доступна |
| Авторизованный | Редирект на `/` |

## UX-заметки

- Тот же визуальный каркас, что у регистрации (пара auth-страниц).
- Поддержать `return` URL с матча.
- **Не класть:** соцлогины в MVP, капчу на первом экране без необходимости, лишний копирайт.

## Связи с другими страницами

- ↔ `/register`.
- → `/forgot-password`.
- → `/` или `/matches/{id}` после входа.
