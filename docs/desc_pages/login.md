# Вход

**URL:** `/login`  
**Статус:** MVP  
**Inertia:** `Auth/Login`

## Зачем страница пользователю

Вернуться в аккаунт, чтобы продолжить picks и видеть свой прогресс в рейтинге.

## Что на экране

### Иерархия

1. Бренд MatchIQ + заголовок «Войти» (каркас как у остальных auth-страниц, тёплая палитра).
2. **Форма:** email · пароль (показать/скрыть) · «Запомнить меня».
3. Ссылка «Забыли пароль?» → `/forgot-password`.
4. Кнопка «Войти».
5. Разделитель «или» + кнопки **Яндекс ID** / **VK ID** (фирменные цвета, SVG).
6. «Нет аккаунта? Регистрация» → `/register`; «К матчам» в шапке.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading (submit) | Кнопка disabled |
| Неверные данные | Сообщение на русском у email |
| Throttle | Сообщение с секундами |
| OAuth не настроен | Flash: «Вход через … пока не настроен» |
| Success | Редирект на intended / `/` |

## Кто видит

| Роль | Доступ |
|------|--------|
| Гость | Страница доступна |
| Авторизованный | Редирект на `/` |

## Связи

- ↔ `/register`, → `/forgot-password`, OAuth `/auth/yandex` · `/auth/vk`.
