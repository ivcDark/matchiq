# Новости

**URL:** `/news` (список), `/news/{slug}` (полная новость)  
**Статус:** MVP (пробные данные)  
**Inertia:** `News/Index`, `News/Show`

## Зачем страница пользователю

Быстро прочитать футбольные и продуктовые новости (РПЛ, кубок, Европа, MatchIQ) и перейти к полному тексту.

## Что на экране

### Список `/news`

1. Заголовок «Новости» и подзаголовок.
2. Сетка карточек (1 / 2 / 3 колонки на mobile / планшете / десктопе), от новых к старым:
   - картинка сверху (16:10) с тегом в углу;
   - дата;
   - заголовок;
   - начало текста (`excerpt`), обрезка до 3 строк.
3. Вся карточка — ссылка на `/news/{slug}`.
4. Пагинация по 12 новостей: «← Новее» / «Старее →» (`?page=N`), показывается только если страниц больше одной.
5. Пустое состояние: «Новостей пока нет» + ссылка на матчи.

### Новость `/news/{slug}`

1. Ссылка «← Все новости».
2. Тег и дата публикации.
3. Заголовок (h1).
4. Картинка.
5. Полный текст (`body`; абзацы разделены пустой строкой). Если `body` пуст — показывается `excerpt`.
6. Блок «Читайте также» — 3 последние другие новости.

Неизвестный slug → 404.

## Данные

Таблица `news_items`:

| Поле | Тип | Назначение |
|------|-----|------------|
| `id` | bigint | PK |
| `slug` | string, unique | ключ в URL |
| `tag` | string(32) | рубрика: РПЛ, Кубок, Европа, MatchIQ… |
| `title` | string | заголовок |
| `image_url` | string(512), null | публичный URL или путь вида `/images/news/{slug}.svg` |
| `excerpt` | text, null | анонс для карточки |
| `body` | text, null | полный текст, абзацы через `\n\n` |
| `published_at` | timestamptz, index | дата публикации |
| `created_at`, `updated_at` | timestamptz | служебные |

### Пробные данные

15 демонстрационных новостей (тексты написаны для MatchIQ своими словами, к реальным событиям не привязаны). Картинки — локальные SVG-заглушки в `web/public/images/news/`.

```bash
php artisan db:seed --class=NewsItemsSeeder
```

Сидер идемпотентен: записи ищутся по `slug` (`updateOrCreate`), даты зафиксированы.

## Навигация

Пункт «Новости» в верхнем меню шапки (после «Рейтинг»), активен на `/news` и `/news/{slug}`. Раздел публичный, доступен гостям и авторизованным.
