# Рейтинг

**URL:** `/leaderboard`  
**Статус:** MVP  
**Inertia:** `Leaderboard/Index`

## Зачем страница пользователю

Увидеть, кто лучше угадывает события, сравнить себя с другими и понять правила очков. Соревновательный слой без соцсети и ленты постов.

## Что на экране

### Иерархия

1. **Шапка** (как на остальных страницах).
2. **Заголовок:** «Рейтинг» + период (минимум один: сезон или «всё время»; если оба — простой переключатель).
3. **Короткая подсказка правил** (2–3 строки):
   - выбираете 1 событие на матч до старта;
   - при успехе: чем ниже вероятность модели, тем больше баллов;
   - при промахе — 0.
4. **Таблица лидеров:**
   - место;
   - ник;
   - очки.
5. Если авторизован и пользователь не в видимом топе — **закреплённая строка «вы»** внизу/под таблицей с местом и очками.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading | Скелетон таблицы |
| Empty | «Пока никто не набрал очков — сделайте первый выбор на матче» + ссылка на `/` |
| Error | «Не удалось загрузить рейтинг» + «Повторить» |
| Гость без аккаунта | Таблица видна; CTA «Зарегистрируйтесь, чтобы участвовать» |

## Что можно сделать

- Смотреть таблицу (гость и пользователь).
- Переключить период (если периодов больше одного).
- Перейти к матчам, чтобы сделать pick; к `/register` / `/login`; к `/me`.

## Кто видит

| Роль | Доступ |
|------|--------|
| Гость | Read-only таблица + CTA на регистрацию |
| Авторизованный | Таблица + подсветка своей строки / закреплённое место |

## UX-заметки

- Простая таблица, не дашборд с графиками.
- **MVP:** один общий рейтинг по picks во всех **активных** лигах (сейчас фактически РПЛ). IA не должна ломаться при появлении 2+ live-лиг: позже — опциональный фильтр «лига / всё» без смены URL-схемы.
- **Не класть:** аватары-галереи, ленту активности, сравнение детальных picks чужих пользователей, сложные фильтры «по турам» в MVP, отдельный рейтинг на каждую «скоро»-лигу.
- Мобильный: колонки место / ник / очки; ник обрезать с ellipsis.
- Подсказка правил — короткая; полный FAQ — на странице «Как это работает» (позже).

## Связи с другими страницами

- ← `/`, `/matches/{id}`, `/me`.
- → `/register`, `/login` (CTA для гостя).
- → `/` — «выбрать событие на матче».

## Реализация MVP-макета

Текущий вид — дизайн-макет на моковых данных (`LeaderboardController`), реального начисления очков ещё нет.

- **Период:** табы «Неделя / Месяц / Сезон / Всё время» → query `?period=week|month|season|all_time` (по умолчанию `season`, неизвестное значение → `season`). Переключение через Inertia без перезагрузки страницы.
- **Модель рейтинга:** рейтинг не обнуляется и ведётся постоянно. Табы «Неделя / Месяц / Сезон / Всё время» — лишь окна (фильтры по времени) по одним и тем же данным, а не отдельные рейтинги.
- **Сезон рейтинга:** единый для платформы, не зависит от сезонов чемпионатов. Действует **с 1 августа по 31 июля** (1 августа 00:00 начинается новый сезон, 31 июля 23:59 последний день старого). Сезон определяется по дате и вычисляется в одном месте — `App\Support\RatingSeason` (`forDate()`, `label()` → «2026/27», `title()`, `range()` → «1 авг 2026 — 31 июл 2027», `contains()`, `toArray()`); моки (`MockLeaderboard::periods()`, `MockUserProfile`) берут сезон оттуда же.
- **Показ сезона:** у таба «Сезон» мелкая подпись «2026/27» и подсказка (`title`); при выбранном периоде «Сезон» под заголовком плашка «Сезон 2026/27 · 1 авг 2026 — 31 июл 2027» с пояснением «Сезон рейтинга действует с 1 августа по 31 июля и не зависит от сезонов чемпионатов» (компонент `SeasonNote.vue`, общий с профилем). Props: `season` (`label`, `title`, `range`, `start`, `end`, `hint`), у `periods[]` для `season` — `caption`, `range`, `hint`.
- **Блок «Как работает рейтинг»:** сворачиваемая кнопка-чип рядом с заголовком «Рейтинг» (`aria-expanded`/`aria-controls`, по умолчанию свёрнута); раскрывает панель `#how-it-works` (компонент `RatingRules.vue`): что такое рейтинг; нумерованные шаги «как набираются очки» (1. выберите одно событие на матч до старта, нужен аккаунт; 2. очки считаются после завершения матча; 3. угадали — чем менее вероятно событие по оценке MatchIQ, тем больше очков, примерно 100 × (1 − вероятность): при 80% около 20, при 30% около 70; 4. не угадали — 0); «Периоды и сезон» (рейтинг не обнуляется, табы — окна по тем же очкам, сезон платформы 1 авг — 31 июл, не зависит от сезонов чемпионатов). Ссылка `/leaderboard#how-it-works` (из профиля «Как считаются очки») открывает блок сразу и прокручивает к нему. Короткая подсказка правил под плашкой сезона остаётся.
- **Формула очков** (источник — `docs/project-context.md`, п. 5.1): `points = round(100 × (1 − p/100) × 1)`, где p — вероятность модели (%) на момент выбора; промах — 0; 1 событие на матч, только до старта; резолв после завершения матча. Реализация для моков — `App\Support\RatingRules::points()`, по ней считаются очки «Самого удачного исхода» в профиле. Суммы в таблице лидеров (`MockLeaderboard`) — грубые макетные числа и по формуле не выводятся.
- **Переходы:** игрок в таблице и карточки топ-3 ведут на [профиль игрока](user-profile.md) `/users/{id}` (по числовому id игрока).
- **Строка таблицы кликабельна целиком:** клик по любой ячейке ведёт на `/users/{id}` (Ctrl/Cmd+клик — в новой вкладке), курсор pointer, мягкая подсветка фона при наведении (sage, transition 160 мс, без смещения вёрстки). Ссылка в нике остаётся настоящей `<a>` — это единственная точка фокуса в строке: Tab/Enter работают с клавиатуры, при фокусе строка подсвечивается и получает левую sage-полосу. Строка «Вы» сохраняет свой lime-фон и полосу pitch и в hover/focus лишь слегка насыщается. Карточки топ-3 — ссылки целиком. `prefers-reduced-motion` отключает анимацию.
- **Топ-3:** карточки с аватаром-инициалами, ником и очками; 1-е место по центру и крупнее (sage), 3-е — coral. На мобильном — вертикальный стек 1 → 2 → 3.
- **Медали 1–3 места:** приглушённые золото / серебро / бронза (токены `--miq-medal-*` в `app.css`; для каждого — основной цвет, `-ink` для крупных цифр и `-on` для текста на цветной плашке, контраст ≥ 5:1). Применяются через `data-medal="gold|silver|bronze"` к карточкам топ-3 (рамка, лёгкий градиент, бейдж места, цвет очков) и к строкам таблицы (мягкий фон, левая полоса, цветной бейдж места, очки цветом; hover/focus насыщеннее). Если игрок «Вы» в топ-3, строка сохраняет цвет медали и метку «Вы» плюс тонкое pitch-кольцо; карточка — pitch-рамку и метку «Вы».
- **Таблица:** место, игрок, прогнозов, угадано, точность %, очки, серия. Мобильный: остаются место / игрок / точность / очки, «угадано из прогнозов» и серия уходят под ник; «Прогнозов» и «Угадано» видны от `sm`, «Серия» — от `md`.
- **Текущий пользователь:** строка (и карточка топ-3, если он там) подсвечивается с меткой «Вы»; в шапке панели — «Ваше место». В моках авторизованный пользователь подставляется на фиксированную позицию.
- **Гость:** таблица видна, внизу CTA «Зарегистрируйтесь, чтобы участвовать».
- **Props (`Leaderboard/Index`):** `period`, `periods[]`, `entries[]` (`rank`, `id`, `name`, `picks`, `correct`, `accuracy`, `points`, `streak`, `is_me`), `totalPlayers`, `currentUserRank`.
- **Стили:** классы `.miq-lb-*` в `resources/css/app.css`, цифры — `.num-display`, заголовок страницы — `.miq-display`.
- **Не сделано:** закреплённая строка «вы» вне топа, состояния loading/error, реальные данные.
- **Тесты:** `tests/Feature/MvpRoutesTest.php` (`test_leaderboard_*`).
