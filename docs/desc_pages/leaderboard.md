# Рейтинг

**URL:** `/leaderboard`  
**Статус:** MVP  
**Inertia:** `Leaderboard/Index`

## Зачем страница пользователю

Увидеть, кто лучше угадывает события, сравнить себя с другими и понять правила очков. Соревновательный слой без соцсети и ленты постов.

## Что на экране

### Иерархия

1. **Шапка** (как на остальных страницах).
2. **Заголовок:** «Рейтинг» + период (минимум один: сезон или «всё время»; если оба — простой переключатель).
3. **Короткая подсказка правил** (2–3 строки):
   - выбираете 1 событие на матч до старта;
   - при успехе: чем ниже вероятность модели, тем больше баллов;
   - при промахе — 0.
4. **Таблица лидеров:**
   - место;
   - ник;
   - очки.
5. Если авторизован и пользователь не в видимом топе — **закреплённая строка «вы»** внизу/под таблицей с местом и очками.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading | Скелетон таблицы |
| Empty | «Пока никто не набрал очков — сделайте первый выбор на матче» + ссылка на `/` |
| Error | «Не удалось загрузить рейтинг» + «Повторить» |
| Гость без аккаунта | Таблица видна; CTA «Зарегистрируйтесь, чтобы участвовать» |

## Что можно сделать

- Смотреть таблицу (гость и пользователь).
- Переключить период (если периодов больше одного).
- Перейти к матчам, чтобы сделать pick; к `/register` / `/login`; к `/me`.

## Кто видит

| Роль | Доступ |
|------|--------|
| Гость | Read-only таблица + CTA на регистрацию |
| Авторизованный | Таблица + подсветка своей строки / закреплённое место |

## UX-заметки

- Простая таблица, не дашборд с графиками.
- **MVP:** один общий рейтинг по picks во всех **активных** лигах (сейчас фактически РПЛ). IA не должна ломаться при появлении 2+ live-лиг: позже — опциональный фильтр «лига / всё» без смены URL-схемы.
- **Не класть:** аватары-галереи, ленту активности, сравнение детальных picks чужих пользователей, сложные фильтры «по турам» в MVP, отдельный рейтинг на каждую «скоро»-лигу.
- Мобильный: колонки место / ник / очки; ник обрезать с ellipsis.
- Подсказка правил — короткая; полный FAQ — на странице «Как это работает» (позже).

## Связи с другими страницами

- ← `/`, `/matches/{id}`, `/me`.
- → `/register`, `/login` (CTA для гостя).
- → `/` — «выбрать событие на матче».

## Реализация MVP-макета

Текущий вид — дизайн-макет на моковых данных (`LeaderboardController`), реального начисления очков ещё нет.

- **Период:** табы «Неделя / Месяц / Сезон / Всё время» → query `?period=week|month|season|all_time` (по умолчанию `season`, неизвестное значение → `season`). Переключение через Inertia без перезагрузки страницы.
- **Модель рейтинга:** рейтинг не обнуляется и ведётся постоянно. Табы «Неделя / Месяц / Сезон / Всё время» — лишь окна (фильтры по времени) по одним и тем же данным, а не отдельные рейтинги.
- **Топ-3:** карточки с аватаром-инициалами, ником и очками; 1-е место по центру и крупнее (sage), 3-е — coral. На мобильном — вертикальный стек 1 → 2 → 3.
- **Таблица:** место, игрок, прогнозов, угадано, точность %, очки, серия. Мобильный: остаются место / игрок / точность / очки, «угадано из прогнозов» и серия уходят под ник; «Прогнозов» и «Угадано» видны от `sm`, «Серия» — от `md`.
- **Текущий пользователь:** строка (и карточка топ-3, если он там) подсвечивается с меткой «Вы»; в шапке панели — «Ваше место». В моках авторизованный пользователь подставляется на фиксированную позицию.
- **Гость:** таблица видна, внизу CTA «Зарегистрируйтесь, чтобы участвовать».
- **Props (`Leaderboard/Index`):** `period`, `periods[]`, `entries[]` (`rank`, `name`, `picks`, `correct`, `accuracy`, `points`, `streak`, `is_me`), `totalPlayers`, `currentUserRank`.
- **Стили:** классы `.miq-lb-*` в `resources/css/app.css`, цифры — `.num-display`, заголовок страницы — `.miq-display`.
- **Не сделано:** закреплённая строка «вы» вне топа, состояния loading/error, реальные данные.
- **Тесты:** `tests/Feature/MvpRoutesTest.php` (`test_leaderboard_*`).
