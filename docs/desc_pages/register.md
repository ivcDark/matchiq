# Регистрация

**URL:** `/register`  
**Статус:** MVP  
**Inertia:** `Auth/Register`

## Зачем страница пользователю

Создать аккаунт, чтобы участвовать в рейтинге (1 pick на матч). Гость уже может смотреть вероятности; регистрация — порог только для соревнования.

## Что на экране

### Иерархия

1. Бренд MatchIQ + заголовок «Регистрация».
2. Одна короткая фраза ценности: «Нужна, чтобы выбирать события в рейтинг».
3. **Форма (минимум полей):**
   - ник (для рейтинга, уникальный);
   - email;
   - пароль;
   - подтверждение пароля (или показать пароль — выбрать один паттерн в дизайне).
4. Кнопка «Создать аккаунт».
5. Ссылка «Уже есть аккаунт? Войти» → `/login`.
6. Ссылка «К матчам» → `/`.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Loading (submit) | Кнопка disabled + индикатор |
| Validation error | Ошибки у полей (ник занят, слабый пароль, email невалиден) |
| Server error | Общее сообщение над формой |
| Success | Редирект: на `return` URL (часто матч) или на `/` / `/me` |

## Что можно сделать

- Заполнить форму и зарегистрироваться.
- Перейти на вход.
- Вернуться к матчам без регистрации.

## Кто видит

| Роль | Доступ |
|------|--------|
| Гость | Страница доступна |
| Авторизованный | Редирект на `/` или `/me` (повторная регистрация не нужна) |

## UX-заметки

- Минимум полей — без телефона, соцлогинов и длинных анкет в MVP.
- Если пользователь пришёл с матча (`?return=/matches/...`) — после успеха вернуть туда, чтобы сразу сделать pick.
- **Не класть:** маркетинговые колонки, карусели, «преимущества Premium».
- Мобильный: одна колонка, крупные поля, клавиатура email/password корректная.

## Связи с другими страницами

- ↔ `/login`.
- → `/` или `/matches/{id}` после успеха.
- → `/forgot-password` не обязателен здесь (есть на входе).
