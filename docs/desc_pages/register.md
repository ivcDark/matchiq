# Регистрация

**URL:** `/register`  
**Статус:** MVP  
**Inertia:** `Auth/Register`

## Зачем страница пользователю

Создать аккаунт, чтобы участвовать в рейтинге (1 pick на матч).

## Что на экране

1. Бренд + «Регистрация» + фраза «нужна, чтобы выбирать события в рейтинг».
2. **Форма:** ник (уникальный) · email · пароль · повтор пароля; подсказка «≥ 8 символов»; показать/скрыть.
3. Клиент: если пароли не совпадают — ошибка у поля повтора, submit заблокирован.
4. Сервер: `confirmed` + сообщения на русском.
5. Кнопка «Создать аккаунт».
6. «или» + Яндекс ID / VK ID.
7. «Уже есть аккаунт? Войти».

## Состояния

| Состояние | Поведение |
|-----------|-----------|
| Validation | Ошибки у полей (ник занят, слабый пароль, email) |
| Success | Логин + редирект на `/` |

## UX

- Без 2FA и email-verify в MVP.
- Тот же визуальный каркас, что у входа.
